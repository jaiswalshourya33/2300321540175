# Stage 1

## Approach

Notifications are fetched from the provided API.

Priority is calculated using:

Placement > Result > Event

Recent notifications are ranked higher than older notifications.

Priority Score:

score = weight × 10000 + recency

Weights:

Placement = 3
Result = 2
Event = 1

## Finding Top 10

1. Fetch notifications.
2. Calculate score.
3. Sort descending.
4. Return first 10.

## Efficient Maintenance

For continuous incoming notifications:

Use a Min Heap of size 10.

Process:

- Insert new notification.
- If heap size > 10:
  remove minimum priority item.

Complexity:

Insertion: O(log 10)
Removal: O(log 10)
Memory: O(10)

This ensures only the Top 10 notifications are maintained at all times.
