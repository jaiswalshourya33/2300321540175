# Stage 1

## Objective
The goal of this project is to display the most important notifications in a Priority Inbox.

## Approach

1. Notifications are fetched from the provided Notification API.
2. The API returns a list of notifications containing ID, Type, Message, and Timestamp.
3. Each notification is assigned a priority based on its type.
4. Notifications are then sorted according to their priority.
5. The top notifications are displayed first in the Priority Inbox.

## Priority Order

1. Placement
2. Result
3. Admission
4. Education
5. Event
Placement notifications are considered the most important and Event notifications are the least important.

### Maintaining Top 10 Notifications

When new notifications are received from the API:

* Fetch the latest notifications.
* Sort them again based on priority.
* Keep only the first 10 notifications.

## Output

The Priority Inbox displays the top notifications fetched from the API, sorted according to their importance.

## Conclusion

The system uses API data and priority-based sorting to ensure that important notifications are shown before less important ones.
